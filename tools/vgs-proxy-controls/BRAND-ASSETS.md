# VGS brand assets

The control panel uses the original VGS website header logo, official favicon,
and Averta Regular / Semibold / Bold WOFF2 fonts. Assets are local so the extension
makes no branding/font requests through the user's session or proxy.

Retrieved 2026-11-18 from the official site:

- Logo: header SVG at https://www.verygoodsecurity.com/
- Icon: https://www.verygoodsecurity.com/favicon.ico (converted to PNG sizes)
- Fonts: https://www.verygoodsecurity.com/fonts/Averta/woff2/hinted-Averta-Regular.woff2
  and the corresponding Semibold and Bold files.
- Colors: VGS navy #002270, purple #8855f7, cyan accents; white surfaces.

These assets retain their owners' rights and are included for this VGS control panel.
