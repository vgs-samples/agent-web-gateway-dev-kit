What is the PAC file?

PAC means Proxy Auto-Configuration. It is a small routing script supplied by this reveal session. The browser uses it to decide which website hosts go through VGS and which use the session’s egress route.

It does not detect checkout automatically. To use VGS only at checkout, start with Egress Proxy, then select Reveal Session Proxy before opening checkout.
