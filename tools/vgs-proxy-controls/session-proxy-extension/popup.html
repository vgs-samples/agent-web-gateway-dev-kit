How PAC routing works
Proxy Auto-Configuration (PAC) is a script supplied by the reveal session. It chooses which hosts use VGS and which follow the session’s egress route.
It does not detect checkout. Choose Egress Proxy while browsing, then Reveal Session Proxy before opening checkout to proxy only that part of the flow.

        Create a service account with the CLI
        

        
Requires a CLI build with the agent-web-gateway-admin template. Check vgs generate service-account --help; if the template is missing, use your team’s updated CLI build.

        
    
          
  1. Sign in
    Sign in with access to create service accounts in your organization. Run these commands in the same Terminal window.
    2. 
          
  2. Generate the account configuration
    Replace the organization and tenant IDs below with the IDs from your dashboard. The tenant must belong to that organization.
    Open service-account.yaml in that folder and review its tenant and permissions before continuing. Generating this file does not create an account.
    The template grants cards:write for card creation, aliases:write, read/write access to reveal sessions and gateway settings. It does not grant PAN/CVC read access. Your organization must have these product scopes enabled.
    3. 
          
  3. Create the account and save its credentials
    This command creates the service account. Its one-time client secret is saved directly to a private local file. Existing files are never overwritten.
    If creation reports an error, stop and check the result before retrying. Keep the credentials file private.
    4. 
          
  4. Connect it here
    Click Browse… above and choose this credentials file, then click Connect account:
    The tenant is read from the file. Use the credentials output, not the configuration file used to create it.
